# Fursat AI — автономная редакция Telegram-канала

Новостной Telegram-канал для Узбекистана: ИИ, заработок, бизнес, технологии и местные возможности.
Система сама собирает новости, проверяет их по первоисточнику, пишет авторский пересказ, рисует
обложку и публикует по расписанию.

- Канал: **Fursat AI**, желаемый адрес `@fursat_ai` («fursat» по-узбекски — «возможность»).
- Стратегия, исследование рынка, рост и финансовая модель: [docs/STRATEGY.md](docs/STRATEGY.md).

## Что нужно сделать владельцу (один раз, около 15 минут)

Эти четыре шага нельзя выполнить без вашего аккаунта Telegram и оплаты API.

1. **Создать канал** в Telegram: публичный, адрес `fursat_ai` (на 14.11.2026 был свободен).
   Название, описание и аватар система поставит сама.
2. **Создать бота**: написать [@BotFather](https://t.me/BotFather) → `/newbot` → скопировать токен.
   Добавить бота в администраторы канала с правами «Публикация сообщений», «Изменение профиля канала»
   и «Закрепление сообщений».
3. **Получить ключ Claude API** на [console.anthropic.com](https://console.anthropic.com) и пополнить баланс.
   Без ключа выйдут только 20 готовых стартовых постов, новые новости писаться не будут.
4. **Добавить секреты** в репозитории: Settings → Secrets and variables → Actions → New repository secret.

   | Секрет | Значение |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | токен от BotFather |
   | `TELEGRAM_CHANNEL` | `@fursat_ai` |
   | `TELEGRAM_ADMIN_CHAT` | ваш числовой id (его покажет [@userinfobot](https://t.me/userinfobot)); перед этим нажмите Start у своего бота |
   | `ANTHROPIC_API_KEY` | ключ Claude API |

Затем на вкладке **Actions** откройте «Fursat AI — редакция» → Run workflow:

- команда `doctor` — проверка, что всё подключено;
- команда `setup` — оформит канал и закрепит приветственный пост.

После этого канал работает сам: запуск каждые 20 минут, 7 публикаций в день.

> Стартовые посты написаны по новостям 12–14 ноября 2026 года. У каждой новости есть срок годности:
> если запуск задержится, устаревшие посты в очередь не попадут.

## Как это устроено

```
источники (RSS) → сбор → дубли и предоценка → AI-редактор → проверки достоверности
                → обложка → очередь → публикация по слотам → аналитика → панель
```

| Этап | Модуль | Что делает |
|---|---|---|
| Сбор | [fursat/collect.py](fursat/collect.py) | 26 лент; сохраняет ссылку, источник, дату, анонс, тему |
| Дубли | [fursat/collect.py](fursat/collect.py) | одна новость из разных изданий склеивается и считается подтверждением |
| Предоценка | [fursat/collect.py](fursat/collect.py) | балл 0–100: тема, доверие к источнику, свежесть; слухи и нерелевантное отсекаются |
| Редактор | [fursat/editor.py](fursat/editor.py) | Claude читает полный текст статьи, решает, публиковать ли, и пишет пересказ |
| Достоверность | [fursat/editor.py](fursat/editor.py) | программные правила поверх модели (см. ниже) |
| Обложки | [fursat/images.py](fursat/images.py) | фирменная картинка 1280×720, свой узор у каждой новости |
| Публикация | [fursat/pipeline.py](fursat/pipeline.py) | слоты по Ташкенту, один пост на слот, срочные новости вне расписания |
| Аналитика | [fursat/analytics.py](fursat/analytics.py) | подписчики, просмотры, реакции, ERR, отчёт по понедельникам |
| Панель | [fursat/dashboard.py](fursat/dashboard.py) | статус в Telegram, в сводке Actions и в `status.html` |

### Правила достоверности

Новость не публикуется, если:

- это слух, утечка или «по данным СМИ» без официального подтверждения;
- полный текст недоступен, источник не первичный и других подтверждений нет;
- источник — агрегатор (Hacker News, Product Hunt) без подтверждения изданием;
- тема — финансы, налоги или законы Узбекистана, а источник не первого уровня и подтверждений нет;
- оценка достоверности ниже 75 или в тексте есть обещания гарантированного дохода.

Редактору запрещено добавлять цифры, цитаты и даты, которых нет в источнике. В каждом посте есть ссылка
на первоисточник.

### Расписание

Слоты по ташкентскому времени: 08:00, 10:30, 13:00, 16:00, 18:30, 20:30, 22:00.
Очередь: срочные новости → свежие новости редактора → стартовые посты. Рубрики чередуются.
Всё настраивается в [config/settings.yaml](config/settings.yaml), источники — в
[config/sources.yaml](config/sources.yaml).

### Где работает

По умолчанию — **GitHub Actions** ([.github/workflows/run.yml](.github/workflows/run.yml)): сервер не нужен.
База SQLite хранится в ветке `state`, суточные копии — в артефактах запусков (30 дней).

Альтернатива — VPS: `python -m fursat loop`. Запускайте что-то одно, иначе посты задвоятся.

## Управление

Команды боту в личные сообщения (работают только от `TELEGRAM_ADMIN_CHAT`, ответ приходит при следующем
запуске, до 20 минут):

| Команда | Действие |
|---|---|
| `/status` | состояние системы |
| `/queue` | ближайшие посты |
| `/skip` | убрать следующий пост из очереди |
| `/pause`, `/resume` | остановить и возобновить публикации |

Бот сам пишет владельцу, если пост не отправился, очередь опустела или канал молчит больше 8 часов.

Локальные команды:

```
pip install -r requirements.txt
python -m fursat doctor            # что настроено
python -m fursat preview           # посты и обложки в data/preview
python -m fursat tick --dry-run    # полный проход без публикации
python -m fursat status            # состояние и HTML-панель
python -m fursat report --days 7   # аналитика
python -m fursat sources           # проверка лент
python -m fursat finance income 50 "реклама курса"   # учёт доходов и расходов
python -m pytest -q
```

## Расходы

| Статья | В месяц |
|---|---|
| GitHub Actions | $0 (публичный репозиторий; в приватном — около 1500 из 2000 бесплатных минут) |
| Claude Opus 5.5, до 18 новостей в сутки | оценка $15–35 |
| Claude Haiku 5.5 (`LLM_MODEL=claude-haiku-5-5`) | оценка меньше $1 |

Оценка расходов на модель расчётная: реальные цифры покажет строка «LLM-токены» в недельном отчёте.
Потолок вызовов в сутки задаётся параметром `editor.daily_limit`.
